چطور اجرا کنیم؟

دیتابیس روی سرور آنلاین بارگذاری شده.
برای اتصال، اطلاعات را از تیم بگیرید و در نوت‌بوک تحلیل وارد کنید.

اگر می‌خواهید دیتابیس را روی سیستم خودتان بسازید:

  ۱. NBA_Scraping.ipynb را اجرا کنید (~۴۰ دقیقه)
  ۲. Data_Cleaning.ipynb را اجرا کنید
  ۳. Build_Database.ipynb را اجرا کنید
  ۴. در نوت‌بوک تحلیل، اطلاعات MySQL لوکال را وارد کنید:

     USER     = "root"
     HOST     = "localhost"
     PORT     = 3306
     DATABASE = "basketball"

پیش‌نیازها:
  pip install requests beautifulsoup4 pandas sqlalchemy pymysql

--------------------------------------------------

خلاصه‌ی تحلیل‌ها

- روند تغییر سبک بازی NBA در ۱۱ فصل
- آزمون فرضیه درباره‌ی BMI، سن و تجربه‌ی تیم قهرمان
- پیشنهاد خرید پوینت‌گارد برای فصل بعد
- رگرسیون خطی برای پیش‌بینی شاخص کارایی بازیکن (PER)
